Проведён аудит UI/UX `frontend/src` по трём направлениям: доступность (a11y), адаптивность/CSS,
UX-состояния. **43 находки**: 8 critical, 10 high, 15 medium, 10 low. Код не изменялся.

### Ключевые находки (для будущих правок)

- `AdminCatalog.jsx:600` — `ReferenceError: album is not defined` (переменная вне scope `albums.map`).
  Клик по альбому в админке = гарантированный белый экран.
- ErrorBoundary отсутствует полностью (grep по `src` → 0 совпадений).
- `App.jsx:132` — глобальный перехват Space: `isTypingTarget` не проверяет `BUTTON`/`A` →
  ни одна кнопка не активируется с клавиатуры.
- Ошибка сети маскируется под «Ничего не найдено»: `MusicLibrary.jsx:455`,
  `searchStore.js:182` (стор пишет `error`, но `UnifiedSearchModal` его не читает),
  `MusicLibrary.jsx:556` (openArtist — тихий no-op).
- z-index: коллизия 8500 (`.tmusic-album-overlay` vs `.tmusic-bottom-nav` — навбар побеждает по DOM-порядку);
  админский тост 8000 < плеер 8400; `CoverPicker` 9000 < fullscreen-плеер 9500.
- `authStore.js:62` — голый `catch` в `checkAuth` → `clearLocalSession()` → `playerStore.reset()`:
  обрыв сети убивает очередь и воспроизведение.
- `api/client.js:131` — при 429 клиент спит 60-300 с внутри себя, затем всё равно бросает ошибку.
- Hover-only контролы на тач-устройствах: `SearchTrackItem.jsx:221` кнопка «в очередь»
  не рендерится без hover; `.tmusic-card-play-btn { opacity: 0 }`.

## Исправление находок (код)

По запросу «исправь все найденные ошибки» внесены правки **только в `frontend/src`**
(commit/push/deployment не выполнялись). Сборка: `node node_modules/vite/bin/vite.js build`
→ ✓ 1688 модулей.

### Новые примитивы (`components/ui/`)

- `ErrorBoundary.jsx`, `Modal.jsx`, `useBodyScrollLock.js` (iOS `position:fixed`),
  `ClickableRow.jsx`, `ConfirmDialog.jsx`+`useConfirm.jsx`, `PromptDialog.jsx`+`usePrompt.jsx`,
  `ToastHost.jsx`.

### Ключевые правки

- UI-01 `AdminCatalog` — `ActionMenu` альбома внутрь `albums.map`; добавлены кнопки-триггеры
  меню (`aria-label`) для строк-с-формой (artist/album), чтобы меню было доступно с клавиатуры.
- UI-05 `MusicLibrary` — `loadError` (+`role="alert"`+«Повторить») и `detailError` (артист);
  тост при сбое запуска альбома. Ошибка ≠ «Ничего не найдено».
- UI-24 — неавторизованным CTA «Войти» вместо пустой сетки.
- UI-04 — `ClickableRow` распространён на карточки, трек-строки, очередь, панели, drop-зону CoverPicker.
- UI-21 — `playBusyId` (pending/disabled) на play-кнопках каталога и плейлистов.
- UI-31 `ProfileMenu` — портал в `document.body`, fixed-позиция, `max-width`, слой `--z-menu` (8800).
- UI-34 — hex → семантические переменные (`--on-accent/--info/--warn/--success/--bg`).
  Внимание: при массовой замене через `sed` шаблоны с кавычками (`'#b5ada2'`) срезали кавычки —
  получалось `color: var(--dim)` без кавычек → ошибка сборки. Заменять без захвата кавычек.
- UI-43 — вордмарк стал `h1`, разделы `h2`, подразделы `h3`.
- UI-18 — удалены инлайновые `outline:'none'`; UI-17 — `vh`→`dvh`.
