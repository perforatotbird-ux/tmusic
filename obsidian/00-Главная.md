## Статус проекта (снимок)

- **Тип:** standalone web-app, выделен из монолита CloudByte
- **Аудит:** 2026-09-15 — критические находки **устранены** (см. [[Устранение уязвимостей]])
- **Аутентификация:** только login+пароль (Argon2id; legacy bcrypt читается для миграции); PIN удалён
- **JWT:** PyJWT HS256, обязательные sub/exp/iat/jti/uid/tv + uid binding + server-side revocation
- **TG-ключи в БД:** Fernet от `SESSION_SECRET`
- **Docker:** non-root `tmusic`, HEALTHCHECK, `no-new-privileges`

---

## Ключевые решения (ADR)

1. [[ADR-001 No God Objects]] — чистые слои, без god-объектов
2. [[ADR-002 Fernet TG Sessions]] — шифрование Telegram-ключей at-rest
3. [[ADR-003 Streaming Cache]] — RAM-кэш + pre-cache + Range
4. [[ADR-004 Cookie Auth CSRF]] — HttpOnly cookie + double-submit CSRF
5. [[ADR-005 Argon2id Migration]] — совместимое чтение legacy, явная смена неоднозначных паролей
