# Архитектура

#tmusic #архитектура

Принцип: **чистая слоистая архитектура без God Objects**. HTTP-роутеры тонкие, бизнес-логика в services, доступ к данным — repositories, транспорт Telegram изолирован в `app/tg/`.

См. также: [[ADR-001 No God Objects]]

## Поток стриминга трека

```mermaid
sequenceDiagram
  participant UI as React SPA
  participant API as FastAPI /api/stream
  participant RAM as RAM Cache
  participant TGM as TG Manager
  participant TG as Telegram Cloud

  UI->>API: GET /api/stream/{id} (cookie или ?token=)
  API->>RAM: lookup by file_id
  alt cache hit
    RAM-->>API: bytes (Range slice)
  else cache miss
    API->>TGM: pick account / failover
    TGM->>TG: MTProto download
    TG-->>TGM: media bytes
    TGM-->>API: stream + optional decrypt AES-GCM
    API->>RAM: store chunk
  end
  API-->>UI: 206 Partial Content / 200
  UI->>UI: <audio> + Media Session metadata
  Note over UI: at 75% progress → precache next 2 tracks (2MB each)
```

## Каталог vs VFS

| Слой | Таблицы | Роль |
|------|---------|------|
| VFS | `folders`, `vfiles`, `folder_closures` | Файловое дерево (треки = `vfiles`) |
| Каталог | `music_artists`, `music_albums` | Витрина: артисты, альбомы, обложки |
| Связь | `folder_id` (FK) | Артист/альбом привязан к папке VFS |

Recursive-обход альбома (multi-disc) — через `folder_closures`.

## Импорт VFS из Replit SQL backup

```mermaid
flowchart LR
  UI["AdminPanel / VFS"] --> API["POST /api/admin/vfs/import/preview"]
  API --> STAGE["data/vfs_imports/*.sql"]
  STAGE --> PARSE["vfs_import_service: COPY parser"]
  PARSE --> PLAN["source folder + target conflict plan"]
  PLAN --> CONFIRM["POST /api/admin/vfs/import/{id}/run"]
  CONFIRM --> MERGE["PostgreSQL transaction"]
  MERGE --> CLOSURE["rebuild folder_closures"]
```

SQL dump не исполняется. Разрешены только `folders`, `folder_closures` и `vfiles`; credentials, DDL, playlists и shares игнорируются. Импортируются VFS metadata и Telegram locators, а не аудиобайты.

Подробнее: [[Импорт VFS из SQL]].

## Маршрут SPA

Catch-all `GET /{full_path:path}` → отдача файлов из `frontend/dist` **только** после `resolve()` + `is_relative_to(FRONTEND_DIST)`, иначе SPA-shell `index.html`.
