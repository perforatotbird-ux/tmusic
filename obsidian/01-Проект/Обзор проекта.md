# Обзор проекта

#tmusic #проект

**T-Music** — автономный веб-сервис потокового воспроизведения аудио и музыкальная витрина поверх облачного хранилища **Telegram**. Выделен из монолита **CloudByte** для независимой работы с музыкальной коллекцией.

---

## Зачем существует

- Высокая скорость и низкое потребление ресурсов
- Бескомпромиссная безопасность при публикации в публичный Интернет
- Изоляция от CloudByte: своя БД `tgmusic`, свой кластер MTProto, свой `music.env`

---

## Ключевые возможности

| Возможность | Суть |
|-------------|------|
| **Zero-Copy Streaming** | Аудио идёт напрямую из Telegram; HTTP 206 Range — мгновенная перемотка |
| **Multi-Account Cluster** | Master/Slave Telegram-аккаунты; при `FloodWait` mid-stream failover на зеркало |
| **In-Memory MTProto** | Сессии Pyrogram с `in_memory=True` — нет конфликтов SQLite-локов |
| **RAM Cache** | Активные треки в RAM, повторные сетевые запросы исключены |
| **Background Pre-caching** | Стартовые 2 МБ следующих 2 треков из очереди |
| **Cover Cache TTL=0** | Обложки на диске перманентно |
| **PWA + Media Session** | Обложка/управление на экране блокировки телефона и авто |
| **Шифрование TG-ключей** | Fernet (`SESSION_SECRET`) в `tg_accounts` |
| **VFS Import из Replit** | Preview и безопасное слияние выбранной папки из plain PostgreSQL SQL backup |
| **E2E-аудио (legacy)** | AES-256-GCM vault — ключи в `ENCRYPTION_RECOVERY_KEY` / fallback |

---

## Целевая аудитория развёртывания

- Личный self-hosted музыкальный сервер
- Доступ из публичного Интернета (Internet-facing)
- Мобильные клиенты / PWA / автомобильная мультимедиа
