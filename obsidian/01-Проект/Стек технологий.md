## Backend

| Компонент | Версия (пин) | Назначение |
|-----------|--------------|------------|
| Python | 3.11+ (рек. 3.13) | Runtime |
| FastAPI | 0.115.8 | HTTP API |
| Uvicorn | 0.34.0 | ASGI-сервер |
| Pydantic Settings | 2.12.0 | Typed config из `music.env` |
| SQLAlchemy 2.0 | 2.0.38 | ORM (Mapped/mapped_column) |
| psycopg2-binary | 2.9.11 | PostgreSQL driver |
| Pyrogram | 2.3.69 | Telegram MTProto клиент |
| tgcrypto | 1.2.5 | C-ускорение крипто Pyrogram |
| PyJWT | 2.10.1 | JWT HS256 + `jti` |
| bcrypt | 4.2.1 | Хэши паролей |
| cryptography | 44.0.0 | Fernet (TG-ключи), AES-GCM vault |
| aiohttp | 3.14.1 | HTTP-клиент (обложки и т.п.) |
| python-multipart | 0.0.20 | Upload cover |
| python-dotenv | 1.0.1 | Env-файлы |

> **Исключено:** `python-jose` (CVE-2024-33663/33664) → PyJWT. `passlib` упоминается в `start_tmusic.bat` как legacy-проверка — в `requirements.txt` его нет; фактическая верификация bcrypt идёт через `bcrypt`.
