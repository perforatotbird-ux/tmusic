# Глоссарий

#tmusic #справка

| Термин | Определение |
|--------|-------------|
| **VFS** | Virtual File System — таблицы `folders` / `vfiles` / `folder_closures`, имитация файлового дерева треков |
| **Closure table** | `folder_closures` — матрица предок/потомок для быстрых recursive-запросов multi-disc альбомов |
| **MTProto** | Протокол Telegram; клиент Pyrogram скачивает файлы «из облака» |
| **session_string** | Сериализованная MTProto-сессия аккаунта; хранится в БД **зашифрованной Fernet** |
| **Fernet** | Симметричный шифр из `cryptography`; ключ = `base64(sha256(SESSION_SECRET))` |
| **FloodWait** | Ответ Telegram rate-limit; триггер mid-stream failover на другой аккаунт |
| **Zero-Copy Streaming** | Отдача медиа клиенту без промежуточной полной записи на диск |
| **Range / 206** | HTTP Partial Content — перемотка без перекачивания всего файла |
| **RAM Cache** | LRU-буфер активных треков в памяти (`RAM_CACHE_MAX_ITEMS`, `RAM_CACHE_MAX_BYTES`) |
| **Pre-cache** | Упреждающая загрузка 2 МБ × 2 следующих трека при ~75% прогресса |
| **jti** | JWT ID — идентификатор отзываемого токена в `revoked_tokens` |
| **token_version** | Счётчик в `app_users`; инкремент при смене пароля инвалидирует старые JWT |
| **Double-submit CSRF** | Readable cookie `csrf_token` + header `X-CSRF-Token` |
| **Scope=stream** | Короткий (10 мин) JWT только для `?token=` в `<audio>` |
| **Magic bytes** | Проверка формата картинки по сигнатуре; **SVG запрещён** (Stored XSS) |
| **SSRF-фильтр** | Блокировка приватных IP/Metadata endpoint при fetch внешних обложек |
| **Self-heal** | При старте сервер перешифровывает plaintext TG-ключи и чинит admin-bootstrap |
| **No God Objects** | Запрет монолитных «делающих всё» классов; разделение api/service/repo/tg |
