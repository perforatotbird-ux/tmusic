# Проверка мобильного приложения после рефакторинга 2026-10-11

#tmusic #mobile #capacitor #refactor #verification

## Область

Проверка, что после рефакторинга архитектуры backend (Service → Repository, см.
[[Аудит архитектуры 2026-10-11]]) мобильное приложение (T-Music Android, Capacitor-обёртка)
продолжает работать: отображение меню и вызовы API.

## Структура мобильного приложения

- `mobile/capacitor.config.ts` — `webDir: 'www'`; `server.url` опционально из `TMUSIC_SERVER_URL`;
  `cleartext: true`; `allowNavigation: ['*']`.
- `mobile/www/index.html` — **стартовый экран**: LAN-discovery (UDP-маяк через
  `AndroidMediaBridge.startNetworkScan`), список найденных серверов, ручной ввод IP. После подключения
  (`connectToServer`) делает `window.location.href = url` → в WebView загружается **SPA с сервера**
  (тот же фронтенд, что и в вебе).
- **Меню** (нижняя навигация, профиль, плеер, поиск, админка) — это компоненты SPA (`frontend/src`),
  загружаемые same-origin с сервера.

## Замечание: CORS и health-check стартового экрана

`mobile/www/index.html` в `init()` делает кросс-ориджин `fetch(saved + '/health', { mode: 'cors' })`
для «мгновенного переподключения» к сохранённому серверу; браузерный fallback — CORS-опрос
`127.0.0.1:8005/health`. Раньше это работало за счёт `CORS_ALLOW_LAN=true` (регэксп матчил `localhost`).
В ходе [[Ревью аутентификации 2026-10-11]] `CORS_ALLOW_LAN` по умолчанию переключён на **False**,
поэтому кросс-ориджин `fetch` к `/health` с ориджина Capacitor (`http://localhost`/`https://localhost`)
может быть заблокирован.

**Влияние:** само приложение работает — при неудаче health-check стартовый экран переходит к
`startDiscovery()` (нативный UDP-скан через `AndroidMediaBridge`), а после подключения SPA
загружается с сервера same-origin (CORS не нужен). Деградация — только «мгновенное переподключение»
к сохранённому серверу.

**Решение (если нужен health-check):** добавить ориджины Capacitor (`http://localhost`,
`https://localhost`, `capacitor://localhost`) в `ALLOWED_ORIGINS`, либо включить `CORS_ALLOW_LAN=true`
для LAN-развёртывания.
