## Что не является подтверждённой ошибкой

- == null / != null в JS здесь используются как null-or-undefined check; сам по себе оператор не требует замены на strict comparison. SQLAlchemy == в Python строит SQL, это не проблема JS coercion.
- return без значения допустим для UI actions, cleanup/logging и side effects; Optional helpers намеренно возвращают None при miss. Не найден отдельный подтверждённый случай missing return, создающий undefined вместо обязательного результата; LOGIC-06 — неправильное значение, а не отсутствие return.
- Ограничения depth и timeout не считаются ошибкой автоматически. Binary search LRC корректно двигает обе границы, collection subtree traversal использует visited; provider retries/redirects и decryption block loop имеют монотонное продвижение.
- Rate limiter sweeper с разными window lengths выглядит как потенциальная проблема общего helper, но текущие project calls используют 60 секунд; как реально проявляющийся дефект проекта не включён.
- Наличие fallback/error handling не гарантирует правильную бизнес-логику: swallowed require/URL errors подтверждены отдельно.
