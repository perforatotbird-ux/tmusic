## Область и метод

Проанализирован весь first-party код: `backend/app` (~77 `.py`), `frontend/src` (59 `.js/.jsx`),
`scripts/`. Исключены `node_modules`, `dist`, `cache`, вендорные бандлы. Проверялись 5 классов:

1. обращение к свойствам без проверки `null`/`undefined`
2. выход за границы массива
3. деление / остаток на ноль
4. необработанные пустые строки
5. необработанный `NaN` (`parseInt`/`parseFloat`/`Number`)

Метод: паттерн-поиск по всему коду (Grep) + ручная проверка **всех** кандидатов.

## Проверено и признано защищённым (примеры)

**Деление / остаток на ноль.** Незащищённых нет.
`App.jsx:284` `cur / dur` — за `dur &&`; `MusicLibraryPlayer.jsx:94-95` — за `max > 0 ? … : 0`;
`StorageSettingsModal.jsx:90` `totalBarSpace = Math.max(totalBytes, 1)`;
`stream_service.py:456-457` `start // block_size`, `start % block_size` — `block_size` клампится
`> 0` в `decryption_service.parse_header:34-35`.

**Границы массива.** Все индексации `[0]`/`[-1]` защищены:
`vfs_import_service.py:531` (`if not matches: raise`), `:1551` (`if not sql_names: raise`),
`subsonic_router.py:903` (`if not shares`), `backup_scheduler.py:31` (`if backups`),
`admin_router.py:179` (`backups[0] if backups else None`), `subsonic_router.py:280`
(`(a.display_name or "#")[0]`), `Modal.jsx:104` (`if (!nodes.length) { …; return }`),
`playerStore.js:790,822` (`if (!tracks || tracks.length === 0) return`),
`playerStore.js:682` (`Array.isArray(saved.queue)`), `client.js:54` (`if (!match) return null`).

**Пустые строки / `int()` на мусоре.** `subsonic_router.py` парсит `size`/`songCount`/`count`/
`rating`/`time` в `try/except (TypeError, ValueError)` (строки 367-370, 397-400, 405-410, 649-652,
661-664, 767-770, 806-809); `lastfm_service.py:213-216` — тоже; `stream_service.parse_range_header:319-330`
ловит `ValueError` и отдаёт полный диапазон; `msg_ids.py:13` — `int(s) if s.isdigit() else None`.

**NaN от `parseInt`/`parseFloat`.** `parseInt` в проекте **не используется вовсе**. `parseFloat` —
только `playerStore.js:183-184` (за `Number.isFinite`) и `MusicLibraryPlayer.jsx:151` (range input).
`Number()` — для ID и с `|| 0`; `retryAfter.js:8-17` — за `Number.isFinite`; `lrc.js:9-10` — за
`Number(x) || 0`; `playbackProgress.js:62,66` — `Number(pos?.… || 0)`.

**Свойства без проверки `null`/`undefined`.** Deep-access на ответах API защищён:
`client.js:27-28` (`item?.loc`, `typeof item?.msg`), `MusicLibrary.jsx:424` (`Array.isArray(res?.missing)`),

`AdminPanel.jsx:476` (`dbStats?.tables?.length > 0`), `playerStore.js:207` (`currentTrack?.id != null`).
