# Как разрабатывать

#tmusic #dev

Короткая инструкция «с нуля до изменения».

---

## 1. Поднять окружение

Windows: [[Запуск Windows]]  
Docker: [[Docker]]  
Config: [[music.env]]

Минимум:
1. PostgreSQL с БД `tgmusic`
2. Заполненный `music.env`
3. `pip install -r backend/requirements.txt`
4. `npm install` в `frontend` (если меняете UI)
5. Admin bootstrap (`init_admin.py` или `ADMIN_PASSWORD_HASH`)

---

## 2. Dev-цикл

### Backend only
```powershell
cd K:\Test\tmusic\backend
python -m uvicorn app.main:app --host 0.0.0.0 --port 8005 --reload
```
API: http://localhost:8005/api/...  
OpenAPI: http://localhost:8005/docs (только если `DEBUG=true`)

### Fullstack
```powershell
# terminal 1 — backend :8005
# terminal 2 — vite :5175 (proxy /api)
cd K:\Test\tmusic\frontend
npm run dev
```
Открывать **5175**, чтобы видеть HMR; API всё равно 8005 через proxy.

### Production-like SPA
```powershell
cd frontend
npm run build
# backend раздаёт dist на :8005
```

## 3. Куда что писать

| Задача | Место |

| Auth | `api/auth_router.py` + `services/auth_service.py` + `core/security.py` |
| Стриминг | `api/stream_router.py` + `services/stream_service.py` + `tg/*` |
| UI экран | `src/components/*` + `src/api/*` |
| Плеер | `src/store/playerStore.js` + `MusicLibraryPlayer.jsx` |
| Конфиг | `core/config.py` + `music.env.example` |
| Скрипт ops | `scripts/*` |
