## Как запускать

```powershell
# из backend/ или корня с PYTHONPATH
cd K:\Test\tmusic\backend
python -m pytest tests/ -q

# только unit
python -m pytest tests/test_security.py tests/test_stream.py tests/test_hardening.py -q

# с живой БД (см. music.env DATABASE_URL)
python -m pytest tests/ -q
```

Требования: установлены `backend/requirements.txt`, для интеграционных — PostgreSQL с БД `tgmusic`.

## Что покрывать при изменениях

- Auth: lockout, token_version, revocation, rate-limit
- Stream: Range, decrypt size, token scope
- Cover: magic-bytes, size cap, auth 401, SSRF host
- SPA: path traversal (regression C-1)
- TG: ensure_encrypted / seal_tg_account
- Bootstrap: default creds **не** возвращаются
