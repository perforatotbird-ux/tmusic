## Как запускать

```powershell
# из backend/ или корня с PYTHONPATH
cd K:\Test\tmusic\backend
python -m pytest tests/ -q

# только unit
python -m pytest tests/test_security.py tests/test_stream.py tests/test_hardening.py -q

# с живой БД (см. music.env DATABASE_URL)
python -m pytest tests/ -q
```

Требования: установлены `backend/requirements.txt`, для интеграционных — PostgreSQL с БД `tgmusic`.

> Live-suite меняет данные тестовой БД и пароль `admin`. Запускать только на disposable database либо со snapshot/restore полей `AppUser`; не использовать production DB без явного окна обслуживания.
