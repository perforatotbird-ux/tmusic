# Сканирование на утечку секретов 2026-10-11

#tmusic #security #secrets #audit

## Область

Полное сканирование репозитория (исходный код, конфиги, `.env.example`, `docker-compose.yml`,
`README.md`, `obsidian/`) на предмет случайно захардкоженных или раскрытых:

- API-ключи, секреты, токены
- строки подключения к БД
- приватные ключи и сертификаты
- внутренние IP и доменные имена
- пароли / учётные данные в комментариях

Инструмент: Grep (ripgrep), уважает `.gitignore`, поэтому реальный `music.env` (хранилище
секретов) не читается и не попадает в результаты. Подтверждено `git check-ignore music.env`
(`.gitignore:2`), файл не отслеживается. Ни одного `.pem/.key/.p12/.pfx/.keystore/.jks` в индексе.

## Результат: критических утечек НЕТ

Все совпадения — это плейсхолдеры в `.env.example`, синтетические тестовые фикстуры,
документация/комментарии без значений, либо регэкспы в скриптах. Ни одного реального
продакшн-секрета в репозитории нет.

## Находки по категориям

| Категория | Статус | Детали |
|---|---|---|
| API-ключи / токены | Чисто | 0 бот-токенов Telegram (формат `\d{8,10}:[A-Za-z0-9_-]{35}` — 0 совпадений); 0 `VITE_`/`REACT_APP_`/`NEXT_PUBLIC_` в клиенте; поля конфига (`config.py`) имеют значения по умолчанию `None`/`""` и берутся из env |
| Строки БД | Чисто | только `music.env.example:12` (`...user:CHANGE_ME@localhost...` — плейсхолдер), regex в `scripts/backup_project.ps1:82`, фикстура в `backend/tests/test_api_security_regressions.py:227` |
| Приватные ключи / сертификаты | Чисто | 0 совпадений `-----BEGIN ... PRIVATE KEY/CERTIFICATE`; ни одного key/cert-файла в индексе |
| Внутренние IP / домены | Низкий риск | см. раздел ниже |
| Пароли в комментариях | Чисто | комментарии упоминают имена переменных, значений нет |

## Внутренние IP / домены (низкий риск, для сведения)

Все — RFC1918 / `.lan`, не публичные; риск раскрытия минимален.

- `music.env.example:37` — пример `TRUSTED_HOSTS=["tmusic.lan","192.168.1.50:8005"]`
- `backend/app/core/config.py:188` — комментарий-пример `["tmusic.lan","192.168.1.50:8005"]`
- `mobile/www/index.html:289` — `placeholder="http://192.168.1.100:8005"` (приватный IP в собранном мобильном ассете `www/`)
- `obsidian/10-Мобильное/Android APK.md:46` — `-ServerUrl "http://192.168.1.100:8005"` (похоже на реальный LAN IP автора в доке)
- `docker-compose.yml:43` — `host.docker.internal:host-gateway` (стандарт Docker, не утечка)
