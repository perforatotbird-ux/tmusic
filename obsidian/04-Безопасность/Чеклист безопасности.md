# Чеклист безопасности

#tmusic #security #чеклист

Перед деплоем / релизом изменения проверить по этому списку.

---

## Конфигурация

- [ ] `music.env` **не** в git / не отдаётся веб-сервером
- [ ] `DATABASE_URL` задан явно (нет implicit кредов)
- [ ] `.secrets/` исключён из Git и Docker build context; права файлов ограничены
- [ ] Раскрытые в истории пароли ротированы во всех местах использования
- [ ] `SECRET_KEY` и `SESSION_SECRET` — уникальные, не дефолтные, не CHANGE_ME
- [ ] `REQUIRE_AUTH=true` в production
- [ ] `ENVIRONMENT=production` (development — только локально)
- [ ] `ALLOWED_ORIGINS` — явный список, без `"*"` при credentials
- [ ] При HTTPS: `COOKIE_SECURE=true`
- [ ] За reverse proxy: `TRUST_PROXY_HEADERS=true` только если прокси перезаписывает XFF
- [ ] `ADMIN_PASSWORD_HASH` задан или пароль выставлен `init_admin.py`
- [ ] `DEBUG=false` (docs закрыт)
- [ ] `LOG_ARCHIVE_PASSWORD` задан и archive logs защищены
- [ ] Last.fm/Discogs ключи — только если нужны

---

## Auth & JWT

- [ ] PIN-эндпоинты отсутствуют в роутере
- [ ] JWT требует sub/exp/iat/jti/uid/tv и связывает uid с user.id
- [ ] Новые пароли Argon2id, legacy login мигрирует без сброса token_version
- [ ] Bcrypt >=72 UTF-8 байт: ограниченная сессия и явная смена, без silent suffix rehash
- [ ] Password KDF concurrency и память измерены на целевом хосте
- [ ] Rollback-версия умеет читать Argon2id; все экземпляры совместимы
- [ ] Login rate-limit ~10/min
- [ ] Lockout 5 / 15 min работает
- [ ] Logout revokes JWT (`revoked_tokens`)
- [ ] change-password инвалидирует старые JWT (token_version)
- [ ] Stream token TTL ≤ 10 min
- [ ] Cookie HttpOnly + SameSite

---

## API hardening

- [ ] Cover endpoints require auth
- [ ] Path traversal regression: `/..%2F..%2Fmusic.env` → SPA-shell, не секреты
- [ ] CSP без `unsafe-inline` в `script-src`
- [ ] Security headers на всех ответах
- [ ] Upload: magic bytes, SVG reject, 10 MB cap
- [ ] SSRF: приватные IP / metadata IP закрыты
- [ ] VFS SQL import: admin permission, CSRF, 256 МБ limit и TTL staging
- [ ] VFS SQL import: raw SQL/credentials не попадают в preview, logs или audit
- [ ] VFS SQL import: `COPY FROM PROGRAM`, бинарный dump и невалидный UTF-8 отклоняются
- [ ] VFS SQL import: конфликты пропускаются, closure table перестраивается

---

## Telegram

- [ ] Все `session_string` / `api_hash` в БД Fernet-encrypted
- [ ] `secure_tg_accounts.py --check` → 0 plaintext
- [ ] `SESSION_SECRET` backup (потеря = невозможность decrypt)
- [ ] Кластер: slaves сконфигурированы для failover

---

## Docker / Host

- [ ] Non-root user в контейнере
- [ ] `no-new-privileges`, `cap_drop: ALL`
- [ ] HEALTHCHECK настроен
- [ ] ports 8005 не закрыты firewall'ом публично без reverse proxy/TLS
- [ ] Volumes `cache/` `data/` permissions корректны
- [ ] PostgreSQL порт хоста привязан к 127.0.0.1; публичный доступ не открыт
- [ ] Для profile db есть локальный secret; POSTGRES_PASSWORD_FILE вместо пароля в YAML
- [ ] Ротация existing volume выполнена в самой БД, а не только сменой файла

---

## Перед production-доступом

- [ ] TLS (Let's Encrypt / reverse proxy) — рекомендуется
- [ ] Backup: `music.env`, PostgreSQL `tgmusic`, `cache/music_covers`
- [ ] Мониторинг логов `tmusic.auth`
- [ ] Dependency updates план (pinned versions — регулярный review)

---

## Запрещено

- Дефолт `admin/admin123`, PIN `1234`
- Unsalted SHA-256 пароли
- `ALLOWED_ORIGINS=["*"]` с credentials
- `REQUIRE_AUTH=false` на internet-facing
- Закоммиченные секреты в markdown/базе Obsidian
- Публичный open cover-proxy

## Текущее исключение CORS

По запросу владельца CORS оставлен без изменений для локального использования. Перед публикацией в Internet отдельно проверить `CORS_ALLOW_LAN=false` и точный `ALLOWED_ORIGINS`; не считать этот пункт закрытым реализацией Argon2id. См. [[ADR-005 Argon2id Migration]].
