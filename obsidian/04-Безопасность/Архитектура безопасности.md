## 1. Brute-force & Rate limiting

| Механизм | Параметр |
|----------|----------|
| Sliding-window per IP | `API_RATE_LIMIT_PER_MIN` (default 120) |
| Auth endpoints | `AUTH_RATE_LIMIT_PER_MIN` (default 10) на `/api/auth/login` |
| Account lockout | `MAX_FAILED_LOGIN_ATTEMPTS=5`, `LOCKOUT_MINUTES=15` |
| Timing attack | `hmac.compare_digest` для legacy + dummy-Argon2id для несуществующего логина |
| Аудит | лог `tmusic.auth` без паролей |

## 2. Аутентификация и JWT

| Требование | Реализация |
|------------|------------|
| Hash | Новые пароли: Argon2id m=65536 KiB, t=3, p=1. Bcrypt и SECRET_KEY-salted SHA-256 читаются для миграции; unsalted SHA-256 отклонён |
| Login | только `POST /api/auth/login` (PIN удалён) |
| Password change | `POST /api/auth/change-password`, 8–128 символов; реальная смена отзывает старые JWT |
| JWT | PyJWT, один настроенный алгоритм (HS256 по умолчанию); обязательные sub/exp/iat/jti/uid/tv, проверка типов, uid=user.id и token_version |
| Revocation | таблица `revoked_tokens` + logout |
| token_version | bump при смене пароля |
| Secrets | `music.env` (не в git) |
| Cookie | HttpOnly, SameSite=Lax; `Secure` при `COOKIE_SECURE=true` |
| CSRF | double-submit cookie + `X-CSRF-Token` |
| Stream token | 10 мин, scope=`stream` |
| Bootstrap | `ADMIN_PASSWORD_HASH` → `ensure_admin_bootstrap` |

## Статус ревью Auth (2026-10-01)

- AUTH-01 исправлен: username/sub дополнительно связан с неизменяемым user.id через uid.
- AUTH-02 исправлен: обязательные claims, строгие типы, резервирование служебных полей при выдаче.
- AUTH-03 исправлен для новых паролей через Argon2id; legacy >=72 байт требуют явной смены с ограниченной сессией.
- CORS_ALLOW_LAN=true по умолчанию доверяет private-range origins с credentials; в production нужен явный allowlist.
- Классическая session fixation не обнаружена; OAuth callbacks отсутствуют.

Изменения реализованы локально в ветке `argon2idmigration`; CORS оставлен без изменений по запросу владельца для локального использования. Нагрузочная проверка на целевом хосте и deployment ещё не выполнены. См. [[Ревью Auth 2026-10-01]] и [[ADR-005 Argon2id Migration]].

## 3. SSRF (cover proxy)

- Async DNS-резолв (thread pool, не блокирует event loop)
- Блок: RFC1918, loopback, link-local, CGNAT, `169.254.169.254` (cloud metadata)
- Только `http`/`https`
- Cover-эндпоинт **требует auth**
- Timeouts: `COVER_HTTP_TIMEOUT_SEC`, `COVER_HTTP_CONNECT_TIMEOUT_SEC`

## 4. Path traversal & Stored XSS

- SPA: `resolve()` + `is_relative_to(FRONTEND_DIST)` (закрыт C-1)
- Cover cache paths: `Path.resolve()` + `is_relative_to(cache_root)`
- Magic bytes image formats; **SVG запрещён**
- Upload limit 10 МБ

## 6. Telegram-ключи

- At-rest: Fernet от `sha256(SESSION_SECRET)`
- Расшифровка: только in-memory при start
- Self-heal только legacy plaintext → encrypted. Fernet format определяется независимо от успешной расшифровки; wrong/missing key и malformed ciphertext fail-closed, запись не перезаписывается. seal проверяет оба поля до ORM mutation, runtime пропускает некорректный account; CLI aborts без commit. Key rotation/repair — отдельная координированная операция.
- CLI: `scripts/secure_tg_accounts.py`

---

## 7. VFS import boundary

- SQL dump принимается только через admin multipart upload с `admin.backups.manage` и CSRF.
- Файл сохраняется под UUID в `data/vfs_imports/`, ограничен 256 МБ и TTL 1 час.
- Dump не исполняется как SQL; parser извлекает только allowlist `folders`, `folder_closures`, `vfiles`.
- `COPY FROM PROGRAM`, бинарный формат и повреждённый UTF-8 отклоняются.
- Preview не возвращает SQL, credentials, `account_map`, session strings или API hashes.
- Импорт использует skip-конфликт, одну DB-транзакцию и rebuild closure table.
- Аудит фиксирует actor, import id и counts, но не содержимое backup.

Подробнее: [[Импорт VFS из SQL]].

## 8. Инфраструктура

- Docker: user `tmusic`, HEALTHCHECK, `no-new-privileges`, `cap_drop: ALL`
- `requirements.txt` зафиксирован (pins)
- `DATABASE_URL` обязателен — fail-fast без неявных кредов
- RAM-cache байтовый лимит (DoS memory)
- `REQUIRE_AUTH=false` допустим **только** при `ENVIRONMENT=development` (иначе RuntimeError)
- OpenAPI `/docs` только при `DEBUG=true`

## Ограничение стоимости password work

Параметры поступивших из БД/ADMIN_PASSWORD_HASH хэшей ограничиваются до запуска KDF. Argon2id verify/hash выполняются вне async event loop; concurrency по умолчанию 2, с process-wide semaphore. При default Argon2id это до 128 MiB памяти KDF на процесс, без учёта остального приложения. Для нескольких процессов бюджет умножается. Не считать unit-тест limiter нагрузочным benchmark.
