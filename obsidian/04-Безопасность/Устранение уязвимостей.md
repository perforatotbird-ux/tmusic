## Критические — закрыты

### C-1 Path Traversal
- `serve_spa`: `candidate = (FRONTEND_DIST / full_path).resolve()`
- Отдача только при `candidate.is_relative_to(FRONTEND_DIST) and candidate.is_file()`
- Иначе SPA-shell `index.html`
- **PoC повторён на живом сервере:** утечка закрыта; легитимная SPA-отдача работает

### C-2 Дефолтные креды
- Удалены из `migrate_data.py`
- Unsalted SHA-256 **отклоняется**
- Legacy SECRET_KEY-salted hash — только миграция, auto-rewrite → bcrypt
- `app/services/bootstrap.py` — `ensure_admin_bootstrap` из `ADMIN_PASSWORD_HASH`
- CLI `scripts/init_admin.py`
- `POST /api/auth/change-password`
- PIN-flow **удалён**

### C-3 Секреты
- `SECRET_KEY` **ротирован** (старые JWT инвалидны)
- `SESSION_SECRET` **не** ротирован (Fernet TG-сессий) — ротация = перевыпуск сессий
- Пароль панели задан bcrypt в `music.env`

## Auth / Argon2id — локальные исправления 2026-10-01

- AUTH-01: проверяется совпадение JWT uid и user.id даже при повторном использовании username.
- AUTH-02: обязательные claims, проверка типов и защита зарезервированных полей при выдаче.
- AUTH-03: запись Argon2id, автоматическая миграция короткого bcrypt/salted SHA-256; bcrypt >=72 байт требует явной смены полного пароля.
- Bounded password workers, актуальный DB-хэш под row lock, one-shot bootstrap и UI смены пароля.
- CORS (AUTH-04) не изменён по явному запросу владельца. Рабочая БД/деплой не затрагивались.
