## UI-17 · `vh` вместо `dvh` — обрезка модалок при показанной адресной строке

# Что проверено и чисто

- **Слайдеры прогресса/громкости** — реальные `<input type="range">` с `aria-label` + `aria-valuetext`
  (`MusicLibraryPlayer.jsx:101-112`, `:143-152`); глобальный `:focus-visible` есть (`index.css:1877-1881`).
- **Оптимистичное избранное с откатом** — `favoritesStore.js:44-80`: точечный rollback только своего id +
  `role="alert"` в `App.jsx:406-411` с кнопками «Обновить»/«Закрыть». Лучший паттерн в проекте.
- **Индикаторы буферизации** — отрисованы во всех состояниях плеера (`MusicLibraryPlayer.jsx:423,492,597,790,966`).
- **AlbumDetail** — полный набор состояний: loading / error / «В этом релизе нет треков» (`AlbumDetail.jsx:385-400`).
- **VFS-импорт** — `window.confirm` с summary, `importBusy`, polling-прогресс, disabled на всех контролах (`AdminVfsImport.jsx:343-394`).
- **Очистка кэша** — двухшаговое подтверждение с выбором категорий (`StorageSettingsModal.jsx:344-444`).
- **Debounce в каталоге** (300 мс, `MusicLibrary.jsx:285-289`) и **abort в поиске** (`searchStore.js:122-133`) —
  гонка «медленный ранний ответ перезапишет новый» в основном запросе закрыта.
- **Горизонтальный скролл страницы** — предотвращён `body { overflow-x: hidden }` (`index.css:41`).
- **iOS auto-zoom в инпутах** — решён `font-size: max(16px, 1rem)` (`index.css:29-31`).
- **`text-overflow: ellipsis` без `white-space: nowrap`** — парных случаев нет, все 4 карточных класса корректны.
- **Обязательная смена пароля** — при `required=true` модалку нельзя закрыть ни Esc, ни кликом по фону, только «Выйти».
