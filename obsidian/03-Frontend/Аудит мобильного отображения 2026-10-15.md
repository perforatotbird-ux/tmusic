# Аудит мобильного отображения 2026-10-15

#tmusic #frontend #mobile #ui #audit

**Причина:** жалоба «в интерфейсе моб приложения куча мелких косяков отображения:
слайдер звука вниз уехал, где-то кнопки друг на друга наезжают».
**Метод:** статический аудит `frontend/src` (плеер, топбар, шит альбома, шапки очереди/текста,
офлайн-баннер) + арифметика компоновки на ширинах 320 / 360 / 380 / 640px.
Устройство для живого прогона не подключалось — визуальная проверка на реальном
телефоне остаётся открытой (см. «Не проверено»).
**Объём изменений:** только `frontend/src` (CSS + 4 компонента) и 1 новый тест;
commit/push/deployment не выполнялись, CORS не затрагивался.

См. [[Аудит интерфейса 2026-10-02]] · [[Структура UI]] · [[Android APK]] · [[00-Главная]]

## Проверки

- `npm run build` → ✓ 1696 модулей, ошибок нет (warning о чанке 614 kB — старый, не связан).

- Backend не трогался; `music.env`/секреты не затрагивались.
